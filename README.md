# Gorig-OM Web 前端管理平台

[Gorig-OM](https://github.com/jom-io/gorig-om) 的现代化运维与性能监控管理 Web 前端面板。基于 React 18、TypeScript、Ant Design 5 与 ECharts 构建。

## 功能特性

- **安全动态认证**：客户端实时生成 10 秒滑动时间窗的加盐 bcrypt 哈希，防御窃听与重放攻击；支持多服务地址切换连接与持久化。
- **系统资源大盘 (Host)**：
  - CPU 核心、系统整体 CPU 与应用进程 CPU 利用率实时指标与时序曲线。
  - 系统内存与应用内存占比监控，磁盘空间使用分布。
  - 资源历史采样明细分页检索。
- **应用生命周期管理 (App)**：
  - 一键触发平滑重启与应用下线，防误触二次确认保护。
  - 重启历史记录追踪，区分手动触发 (`manual`)、CI/CD部署 (`deploy`)、崩溃自愈 (`crash`) 与超载保护 (`overuse`)。
  - 原生支持守护进程与崩溃现场日志查看。
- **日志中心 (Logs)**：
  - JSONL 日志结构化检索（类目、级别、TraceID、关键词、时间范围精确匹配）。
  - 日志行前后上下文（Near）反查抽屉。
  - 原始 `.jsonl` 日志文件安全下载。
  - **基于 SSE (Server-Sent Events) 的实时高亮滚动日志终端**，支持启停控制、实时关键字过滤与自动滚屏。
- **API 性能统计 (APM)**：
  - 请求总量、2xx 平均响应延迟、5xx 错误数、慢请求 (>200ms) 概览。
  - 流量分布（2xx/4xx/5xx）与耗时趋势时序图。
  - API 接口排行榜（支持按耗时、调用量、状态码筛选与排序）。
  - 接口抽样分析抽屉（入参、出参、错误堆栈与耗时详情）。
- **错误特征签名追踪 (Error Signatures)**：
  - 错误时序走势图（Warn / Error / Panic / Total）。
  - 自动正则归一化聚类生成异常签名，统计发生频次、首末时间与抽样 Trace。
- **协程与内存诊断 (Runtime & Mem)**：
  - Goroutine 协程数量走势与暴涨预警。
  - 基于 Heap Profile 解析在用内存大对象 Top50（定位至具体函数与源码行）。
  - GC 滑动窗口内存泄漏异常捕获、增长总量及嫌疑函数调用栈分析。
- **CI/CD 自动化部署流水线 (Deploy)**：
  - Git / Go 编译环境版本检测与一键自动安装。
  - 机器部署 SSH 公钥管理（查看、一键复制、重新生成）。
  - Go 编译环境变量（GOPROXY、GOPRIVATE 等）在线配置。
  - Git 仓库与分支动态选择、多子仓依赖配置、远端提交自动触发。
  - 任务部署实时步骤日志滚动终端与**一键秒级历史版本回滚**。

## 技术栈

- **构建工具**：Vite 6
- **核心框架**：React 18 + TypeScript
- **组件库**：Ant Design 5 + @ant-design/icons
- **图表可视化**：ECharts 5 + echarts-for-react
- **样式方案**：Tailwind CSS
- **状态管理**：Zustand
- **网络请求**：Axios (自动拦截与 JWT 注入)
- **安全加密**：bcryptjs (防重放 10s 时间窗动态加盐哈希)

## 快速上手

### 1. 安装依赖

```bash
npm install
```

### 2. 本地开发启动

```bash
npm run dev
```

启动后访问 `http://localhost:5173`。开发服务器默认已配置反向代理：
- `/om/**` -> `http://127.0.0.1:9617`（宿主 Gorig 服务的默认端口）

### 3. 连接与登录

1. 打开登录页面，输入目标服务地址（本地可留空，或填 `http://127.0.0.1:9617`）。
2. 输入宿主服务在配置文件中设定的 `om.key`。
3. 点击 **连接并进入控制台**，系统将自动生成时间窗哈希并换取会话 Token。

### 4. 生产构建打包

```bash
npm run build
```

构建产物输出至 `dist/` 目录，可直接部署在 Nginx、Caddy、对象存储或静态网站托管平台中。
